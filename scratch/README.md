# scratch/: exploratory scripts (not canonical)

These reproduce side remarks in notes §5.1(e). They were recreated for this repo from the original session transcript. `bond2.py` reproduces its original output for seed 1.

- `bond2.py`: Golay/code2 rings with 2-dimensional bonds (81×81 transfer matrices). Power sums grow like random codes.
- `localcells.py`: 1-dim-bond cells with low-weight bond vectors. Each is nilpotent or has spectral radius ≳ 12.

Canonical checks live in `ternary60/theory/existence_*.py`.
