## Suggested edits (wording and hedging; none affects correctness)

1. **Numbering of GJF.** "Conj. 1.4", "Question 0.1", "Thm 1.3" follow the arXiv version (unnumbered intro).
   The CJM version could differ. Add a footnote: "Numbering refers to the arXiv version."
2. **"Lengths 72 and 84 were the first cases not previously known."** This is a literature claim that the
   pending citation search has not yet backed. Safer: "not covered by the examples of [GJF] (k ≤ 5) or by
   doubling (k = 2^j)."
3. **Verification remark, "exhaustive enumeration of 2^{n/2−1} words".** Unexplained as written. Say: a
   maximal codeword is nonzero on an information set, so the 2^{n/2} sign patterns there (2^{n/2−1} up to
   x ↦ −x) exhaust the candidates; the count is sign-exact when done without normalisation. Optionally add
   that the sign-exact value at n = 36 is +24 (paper_check.py).
4. **Definition (partial quadrupling), "each split into the pairs shown".** Ambiguous for {p,p*,q,q*}.
   Write "split arbitrarily into two pairs; by Lemma 2 the choice is immaterial", and say the same for σ″ in
   the main lemma. (R_σ itself never depends on the splits, only Q_σ does.)
5. **Last remark, "generator matrix of size polynomial in k".** Trivially true (6k × 12k). Say instead
   "computable in time polynomial in k" or drop it.
6. **Last remark, "a weight-3 word forces the index to vanish".** Add "by self-duality": for a maximal x and
   a weight-3 codeword w, ⟨x,w⟩ = 0 forces x to agree with w or with −w on supp w, so one of x ± w is maximal, with the opposite sign.
7. **Proof of the theorem, even k.** Say "k = 2j + 2, j ≥ 0" so that "applying the engine j times" is
   unambiguous.
8. **Intro.** "GJF prove the divisibility statement except for lengths ≡ 12 (mod 24)" is right, but the
   paper is then silent on that case although notes §1–2 prove it. Either cite the companion argument or
   add one sentence saying the divisibility half is treated elsewhere.
9. Placeholders to fill: `\author{[Draft --- authors to be added]}`, "available at [repository]".
10. Optional: cite Conway–Sloane only for the tetracode/Golay facts used (weights, two words per 3-set, weight
    enumerator), and state that Lemma 2 holds for any code monomially equivalent to T (used implicitly when
    T is placed on β* and B**).
